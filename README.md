# Breakpoint Lab Studio

Vidéos courtes **Breakpoint Lab** (@BreakpointLabTV) : *satisfying science, tested for real.*

- `engine/engine.html` — série **Tests** : banc d'essai 3D (presse, traction, chute), casse aux valeurs publiées.
- `engine/physics.html` — série **Physics** : expériences (courses de billes sur cycloïde…), mouvements calculés par les lois physiques.
- `engine/render.js` — rendu image par image (Chromium headless, WebGL) ; `engine/audio.py` — son procédural.
- `configs/*.json` — un épisode par fichier (voir `engine/README.md`).
- `.github/workflows/render.yml` — rendu parallèle sur GitHub Actions → Google Drive.

Épisodes : `concrete_c30_37_en` (cube de béton, EC2), `egg_standing_vs_lying_en` (œuf, MIT 2025), `physics_001_ball_race_en` (brachistochrone + tautochrone).
